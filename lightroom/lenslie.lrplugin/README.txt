LENSLIE – WTYCZKA DO LIGHTROOM CLASSIC
======================================

Instalacja
1. Przenieś folder "lenslie.lrplugin" w stałe miejsce (np. Dokumenty/Lightroom).
2. Lightroom Classic → Plik → Menedżer zewnętrznych modułów (Plug-in Manager) → Dodaj → wybierz "lenslie.lrplugin".
3. W lewej kolumnie modułu Biblioteka, w panelu "Usługi publikowania", kliknij "Skonfiguruj" przy Lenslie.
4. Wpisz e-mail i hasło do Lenslie i kliknij "Zaloguj", potem "Zapisz".

Użycie
- Prawy przycisk na "Lenslie" → Utwórz kolekcję → nazwa = nazwa galerii (np. "Ślub Anny i Marka").
- Przeciągnij zdjęcia do kolekcji i kliknij "Publikuj".
- Poprawiłeś zdjęcie? Trafi do "Zmodyfikowane zdjęcia do ponownej publikacji" – kliknij "Publikuj".
- Usunięcie zdjęcia z kolekcji usuwa je też z galerii.
- Galerię dla klienta publikujesz (wybór pakietu) w panelu www.lenslie.com.

Wtyczka działa w Lightroom Classic (nie w Lightroom w chmurze).
Pomoc: https://www.lenslie.com/panel/lightroom

-----

LENSLIE – LIGHTROOM CLASSIC PLUG-IN

1. Move the "lenslie.lrplugin" folder to a permanent location.
2. Lightroom Classic → File → Plug-in Manager → Add → choose "lenslie.lrplugin".
3. In the Library module, in the Publish Services panel, click "Set Up" next to Lenslie.
4. Enter your Lenslie e-mail and password, click "Sign in", then "Save".
Create a collection (= gallery), drag photos into it and click "Publish".
